# LAUNCHMATE

Free-first business idea validation and launch planning workspace.

## What it does
- Capture and refine a business idea
- Score launch readiness across key factors
- Estimate startup budget, revenue, costs, and gross margin
- Build a practical launch checklist and action plan
- Save work in the browser and export it as JSON, CSV, or TXT

## Run locally
No build step or paid service is required.

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

## Deployment
The current live deployment is https://launchmate-one.vercel.app

GitHub repository: https://github.com/suniljaiswar657-dotcom/launchmate

## Privacy
This version stores workspace data in the browser's local storage. It does not require a backend, account, or API key. Data stays in the browser unless the user exports it.

## Status
MVP implementation. No external AI API is connected in this version; plan generation uses local templates and entered data.
